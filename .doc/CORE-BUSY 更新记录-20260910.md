## 2026-09-10 12:05 — Phase 2 硬件监控（温度/功耗/频率/P-E 拓扑）

- `LogicalProcessorTopologyService`：P/Invoke GetLogicalProcessorInformationEx(RelationProcessorCore)，输出每逻辑处理器的物理核心号与 EfficiencyClass；Intel 混合架构 EfficiencyClass>0 为 P 核、=0 为 E 核，非混合平台（如 AMD Zen）全部归为 P 核；支持多处理器组（GroupCount）掩码展开。

- `PerCoreUsageProvider`：PerformanceCounter（Processor / % Processor Time），实例名 0..N-1 匹配逻辑处理器数；采样异常按 0 兜底不崩溃。
- `CoreStatusClassifier`：按方案 3.2 节阈值分类（0-5 摸鱼 / 5-20 空闲 / 20-50 工作 / 50-80 忙碌 / 80-95 高负载 / 95-100 爆肝）。

Task 4（核心 Tile UI）：
- `MainViewModel` + `CoreTileViewModel`（ObservableObject 手写轻量 MVVM，无第三方依赖）；DispatcherTimer 1000ms 采样刷新，UI 不阻塞。
- 主界面：头部 CPU 名称/厂商/核心线程汇总/平均占用，WrapPanel 核心 Tile（名称/百分比/状态，状态配色由冷到热），底部状态栏；温度/功耗与热力图入口按 Phase 2/3 预留占位。

Task 5（托盘运行）：
- NotifyIcon 托盘（程序化绘制 2x2 核心方格图标，无二进制资源）；关闭/最小化隐藏到托盘，双击还原，托盘菜单"显示主窗口/退出"；ShutdownMode=OnExplicitShutdown 保证托盘常驻。
